# 攻防标签（Armor Class）映射表

> 2026-10-15 定稿。对应《改动大纲》第 2 节「整理单位攻防标签」。
> 2026-10-16 修订：101+ 新标签补全为「三维度单属性 + 全排列组合」体系（105–112）；修正二/三节与一节定稿的矛盾（5/25/27/28 为沿用）；11 从合并清单拆出，作为攻城武器对建筑专用加成通道（21 保留给步兵/骑兵）。
> 护甲类只参与伤害计算（攻击加成 vs 护甲值），不驱动任何引擎行为；引擎行为走单位"种属"（class），与本表无关。

新增攻防类型统一从 **101** 号段开始，便于维护。101+ 围绕三个维度展开——**攻击方式**（近战/远程）、**兵种**（步兵/骑兵）、**重量**（轻型/重型）——先列单属性，再列三维度的全排列组合。兵种维度沿用官方 步兵(1)/骑兵(8)，不占新号段。

### 单属性标签（101–104）

| 模组标签 | class ID | 维度   | 说明                                   |
| ---- | -------- | ---- | ------------------------------------ |
| 近战单位 | **101**  | 攻击方式 | 与基础近战护甲(4)区分：3/4 是护甲值，101/102 是身份标签，供攻击加成指向 |
| 远程单位 | **102**  | 攻击方式 | 同上                                   |
| 轻型单位 | **103**  | 重量   |                                      |
| 重型单位 | **104**  | 重量   |                                      |

### 组合标签（105–112，三维度全排列 2×2×2）

| 模组标签  | class ID | = 组合      | 代表单位             |
| ----- | -------- | --------- | ---------------- |
| 轻型近战步兵 | **105**  | 轻型+近战+步兵  | 长矛兵系、鹰斥候系、蔷琵系    |
| 重型近战步兵 | **106**  | 重型+近战+步兵  | 剑士系              |
| 轻型远程步兵 | **107**  | 轻型+远程+步兵  | 步弓手系、弩手系、火枪手     |
| 重型远程步兵 | **108**  | 重型+远程+步兵  | （预留，暂无单位）         |
| 轻型近战骑兵 | **109**  | 轻型+近战+骑兵  | 斥候骑兵系、骆驼兵系       |
| 重型近战骑兵 | **110**  | 重型+近战+骑兵  | 骑士系、黑光铠骑兵系       |
| 轻型远程骑兵 | **111**  | 轻型+远程+骑兵  | 骑射手系、骑马弩手系       |
| 重型远程骑兵 | **112**  | 重型+远程+骑兵  | 骑象射手系            |

- 挂牌规则：每个单位同时挂 **3 个单属性 + 1 个组合标签**（组合与单属性叠加而非替代）——加成想打宽指向单属性（如 vs骑兵(8) 打全部骑兵），想打窄指向组合（如 vs轻型近战步兵(105) 只打矛系/鹰系而不误伤剑士）。
- 不设「近战骑兵」等二维组合：打宽用单属性即可覆盖，组合标签只保留最细粒度。
- 象类/火药/独特等单位在组合标签之外再叠加身份标签：大象(5)、火药(23)、独特(19)、长矛兵(27)、远程骑兵(28)。

## 五、实施要点

1. 重写范围：所有 PVP 对战单位的护甲列表与攻击加成全部按新体系重写（`unit_changes`）。
2. 建筑：近战/远程护甲 200，身份标签双通道——21 = 步兵/骑兵对建筑加成，11 = 攻城武器对建筑加成（墙/门两者均为 5，其余建筑 0）；远程单位攻击建筑吃保底伤害 1。
3. 组合标签与单属性叠加使用（如骑士 = 骑兵(8)+近战(101)+重型(104)+重型近战骑兵(110)）。
4. 新增 class 一律使用 101+ 号段，下一个可用 ID：**113**。
